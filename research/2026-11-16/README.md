# Measurements, 2026-11-16

Last verified: 2026-11-17.

These are the first model measurements on this laptop: gpt-oss-20b on llama.cpp and on vLLM, and Qwen3.8-27B, Qwen3.6-35B-A3B, Gemma 4 26B-A4B, K2 Horizon 7B and MoVA, Qwen3-Coder-Next, Nemotron 3.5 Bolt and Lightning, Groot-19B-A3B and DeepSeek-R1-0528-Qwen3-8B on llama.cpp, plus five small models from the LibreDB Studio list on Ollama 0.40.16, with the same probe script and the same OpenCode task.
The curated results are in [llamacpp/models.md](../../llamacpp/models.md) (one section per model), [llamacpp/benchmarking.md](../../llamacpp/benchmarking.md#results-template), [vllm/models.md](../../vllm/models.md#gpt-oss-20b) and [vllm/benchmarking.md](../../vllm/benchmarking.md#results).
Do not edit these records by hand.
Before the repository went public on 2026-11-16, a script replaced local paths in these records and scripts with `$HOME`, `$SCRATCH` and `$SESSION`; to rerun a script, set `SCRATCH` to a work folder first.

## Setup

- Machine: RTX 5080 Laptop GPU (16,303 MiB per `nvidia-smi`, 15.47 GiB per CUDA), driver 595.99.02, 140 W limit, Ubuntu 26.04.1, Docker 29.9.3, NVIDIA Container Toolkit 1.20.1.
- Probe: [llm_probe.py](llm_probe.py), standard library only; it runs the OK test, a tool-call test, three decodes of up to 1,500 tokens, and 8k and 30k prompts (plus 100k for the 128k models) sent twice to see the prompt or prefix cache.
  From Gemma 4 on, [measure.sh](llamacpp-gemma-4-26b-a4b/measure.sh) wraps the probe, a per-request thinking check, a code-generation decode and the OpenCode run in one procedure.
- OpenCode: v2.3.0 `run --standalone --archived --auto --format json` in a scratch folder with [opencode-test-config.json](opencode-test-config.json), which denies shell, web, task and skill tools; the task was to write `hello.py` and read it back.
  From Gemma 4 on, the runs use [opencode-test-config-v2.json](opencode-test-config-v2.json), the same config with entries for the next eight models.
  The Ollama runs use [opencode-test-config-v3.json](opencode-test-config-v3.json), which adds an `ollama-local` provider with `maxTokensField: max_tokens`.
- Ollama: `ollama/ollama:0.40.16` with the GPU, the `ollama-models` volume, explicit `OLLAMA_CONTEXT_LENGTH` and KV type, flash attention and one slot ([measure-ollama.sh](measure-ollama.sh)); the tags were pulled first in a container without a GPU, pinned to E-cores 16-23 ([ollama-pull.sh](ollama-pull.sh)), and measured one at a time ([ollama-driver.sh](ollama-driver.sh)).
  Each Ollama run adds the LibreDB Studio native `tool_calls` probe and records the version, model digest, `ollama ps` and the bundled `llama-server` log.
